语言包管理

翻译默认全部在你的浏览器里完成，不配置也能用。首次使用某个方向会下载对应语言包，之后可离线使用。

模型来源：Mozilla Firefox Translations　·　许可证：MPL-2.0　· 运行时：bergamot-translator（MPL-2.0）

AI 引擎（自带 Key，质量最高）

填入任意 OpenAI 兼容服务（DeepSeek / 通义 / GLM / OpenAI）。启用后翻译文本会发送给该服务商；不启用则全部本地。

Key 只存本机（chrome.storage），只发往你填写的接口地址。

生词本

选中翻译卡片上的「收藏」把生词存到这里；CSV 可直接导入 Anki（正面=原文，背面=译文）。
