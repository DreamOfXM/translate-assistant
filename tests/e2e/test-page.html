用这个普通 HTML 页面验证扩展的完整闭环。首次翻译某个方向会下载语言包（约 25–50 MB），之后可断网重试验证离线能力。

1. 选中文本翻译

Local machine translation runs entirely on your device. Once the language pack is downloaded, no network connection is required and no text ever leaves the browser.

选中上面任意英文，应出现「翻译选中」按钮 → 点击后弹出结果卡片。

この拡張機能はブラウザの中で翻訳を実行します。テキストが外部に送信されることはありません。

选中日文，验证源语言自动识别为日语。

2. 长文本分段

The purpose of this paragraph is to exercise the segmentation path of the extension. It needs to be comfortably longer than the single request limit so that the content script decides to split the text into several segments before sending anything to the translation engine. A naive implementation would simply truncate the tail of the text and quietly lose the rest of the paragraph, which is exactly the behaviour this test is meant to catch. When you select the whole paragraph and translate it, the status line should report how many segments were used, and the final result should contain a translation of the very last sentence as well, not just the first few ones. If the translation stops in the middle or drops the ending, segmentation is broken and the request length limit is being applied incorrectly somewhere along the path between the content script, the background service worker and the offscreen engine host. Keep reading to the end of this sentence to make sure nothing has been silently discarded along the way.

整段选中翻译，状态栏应提示「已分 N 段翻译完成」，且末尾句子也应被翻译。
