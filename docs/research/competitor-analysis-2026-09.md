# 翻译扩展全网竞品调研（2026-09）

> 三路并行调研：沉浸式翻译深挖、其他玩家、用户痛点与技术实践。结论已按「我们怎么做」落地为 ROADMAP。

## 一、市场格局

| 玩家 | 装机量 | 定位 | 强项 | 弱项 |
|---|---|---|---|---|
| 沉浸式翻译 | 400 万+（4.6★） | 双语对照开创者、全场景 | 双语范式、视频字幕/PDF/EPUB、20+ 引擎聚合、千万口碑 | 云端强依赖、闭源、免费额度缩水、Pro 推销、性能 |

## 二、沉浸式翻译的软肋（我们的进攻点）

1. **隐私信任危机**（V2EX 2025 爆帖：上传令牌、快照泄露敏感信息）——闭源+云端+被收购
2. **免费额度持续缩水**：下架免费引擎、强制登录、每日配额触顶、自带 Key 也不完全豁免
3. **性能**：长页/HN 类高密度文本卡顿、CPU 飙升、请求排队
4. **定价**：Pro 约 ¥580/年，用户要求按量付费

## 三、用户痛点 TOP8（全网汇总）

隐私泄露与信任危机 / 自动翻译关不掉乱触发 / 翻译悄悄改变原意 / SPA 动态内容失效漏译 / 无双语对照（Google 整体替换）/ 视频字幕支持差 / 翻译失败不稳定 / 商业化骚扰

## 四、AI 时代新体验

整段上下文注入（代词/术语准确率大升）、术语库一致性、自定义 prompt 译风、多引擎混排、流式逐段上屏、双语样式自定义、Markdown 保留

## 五、技术最佳实践

content script 抽文本节点 + background 调 API（隔离密钥/CORS）；IntersectionObserver 视口懒翻译 + MutationObserver 兜 SPA；段落去重缓存、批量请求；shadow DOM/iframe/translate=no 兼容；双语注入不破坏布局。

**我们已具备**：懒翻译（视口+MutationObserver）、shadow DOM、iframe 子框架注入、正文根判定+噪音过滤全家桶、暗色适配、双语 i18n、Chrome 端侧引擎+本地语言包双引擎。

## 六、我们的定位（结论）

**「本地优先、开源、无配额」的翻译扩展**：
- 别人的核心弱点（隐私、配额、推销）正是我们的核心卖点（端侧引擎、开源可审计、无配额）
- 基线功能补齐：修饰键悬停即翻、快捷键、站点规则 UI、AI 自带 Key 引擎
- 远期差异化：Trancy 式「翻译→学习」闭环（生词本/语法分析）、DeepL 式输入框润色、PDF/字幕

## 七、本次落地（对应 ROADMAP）

1. 修饰键悬停即时翻译（Alt/Ctrl 悬停段落直接出双语）
2. 全局快捷键 Alt+T 切换整页双语
3. 站点规则从硬编码升级为用户可配置（options 管理 + popup 本站快捷开关）
4. AI 引擎（BYO Key，OpenAI 兼容接口：DeepSeek/Qwen/GLM/OpenAI）——质量上限打开，付费档形态
5. 翻译链优先级：AI（用户配置）→ Chrome 内建 → 本地语言包
